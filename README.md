# CANIM ANEM — The Art of a Beautiful Heart
*An immersive, cinematic birthday experience for Anem, crafted with love and devotion by Anas.*

---

## 🌸 Overview
CANIM ANEM is a bespoke digital gift and cinematic birthday letter. Built with React 18, TypeScript, Tailwind CSS, and Framer Motion, it seamlessly blends:
1. **Japanese Sakura Dream**: Falling cherry blossoms, tranquil morning light, and garden motifs.
2. **Bali Tropical Paradise**: Turquoise waters, palm silhouettes, and warm golden sunset vistas.
3. **Luxury Feminine Editorial**: Warm ivory handmade paper texture, champagne-gold accents, wax seals, and refined typography.

---

## 📜 Story Architecture & Chapters
The experience guides the visitor through four core chapters:
- **Chapter 01**: *Sizin Güzelliğinizin İzleri* (Appreciation of Anem's timeless beauty reflected in Sude and Ilayda)
- **Chapter 02**: *Sesiniz, Zarafetiniz ve Güzel Kalbiniz* (Admiration for her gentle voice, accent, open-mindedness, and pure heart)
- **Chapter 03**: *Hayata Duyduğunuz Sevgi* (Her travel passions in Japan & Bali, the mother's kitchen table, Erol Baba, Sude, and heartfelt birthday blessings)
- **Chapter 04**: *Ve Ilayda... Kalbimin En Güzel Hikâyesi* (The romantic climax: Ilayda's portrait reveal, Anas's deep love, vows of marriage, and the two-stage highlight statement)
- **Grand Finale**: Heirloom portrait return, sequential birthday affirmations, and Anas's animated handwritten signature with celebration effects.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
```
The optimized static assets will be generated in `dist/`.

### Preview Production Build
```bash
npm run preview
```

---

## 🎨 Asset Configuration
All primary media assets reside in `/public/assets/`:
- `anem-photo.jpg` & `anem-photo.webp`: Original and optimized portraits of Anem.
- `ilayda.jpeg` & `ilayda.webp`: Original and optimized portraits of Ilayda.
- `birthday-song.mp3`: *"When God Made You My Mother"* by Riley Roth.
  - Configurable playback start/end timestamps are managed in `src/data/audio.ts`.
